# Default Permission Matrix

Role Permissions are only a baseline. Super Admin can modify role permissions and add/remove User overrides.

- SUPER_ADMIN: full system access, with the safety rule that the last manageable Super Admin cannot be disabled or stripped of all administration ability.
- ADMIN: operational work in scoped services.
- GENERAL_SECRETARY: visibility-oriented operational baseline over scoped services.
- SECRETARY: one service; opening access plus configurable operational permissions.
- ASSISTANT: one service; opening access plus transfer/swap permission as baseline.

Screen settings are independent: SHOW / VIEW / EDIT / OTP_REQUIRED.
